As 7 skills de animação que testamos

Skills são pacotes de instruções que o Claude carrega quando precisa. Estas ensinam animação, vídeo e 3D. Este vídeo foi feito com duas delas:

Como instalar: abra o terminal na pasta do seu projeto e cole o comando. Precisa do Node.js instalado. Depois, é só pedir no Claude Code, por exemplo: “use a skill hyperframes para fazer um vídeo de 10 segundos com o meu logo”.

1. HyperFrames

Escreve a animação em HTML e renderiza em MP4. Feita pela HeyGen.

npx skills add heygen-com/hyperframes

Testado aqui: o vídeo acima, 12 segundos em 1080×1920, renderizado em cerca de 1 minuto.

2. Remotion

Vídeos escritos em React: cria o projeto, legendas, mapas e áudio. Boa para quem já programa.

npx skills add remotion-dev/skills

Grátis para pessoas e empresas com até 3 funcionários. Acima disso, precisa da licença paga.

3. GSAP

Skills oficiais da GreenSock: linha do tempo, ScrollTrigger, React, plugins e desempenho.

npx skills add greensock/gsap-skills

O vídeo acima é animado com uma linha do tempo do GSAP.

4. Three.js

Cenas 3D no navegador: materiais, luz, sombras, shaders, animação e carregamento de modelos.

npx skills add cloudai-x/threejs-skills

Testado aqui: rodamos o exemplo inicial da skill e saiu a gema laranja do carrossel.

5. Motion Design

Princípios de animação: duração, curvas, coreografia. Funciona com CSS, GSAP, Framer Motion ou Lottie.

npx skills add LottieFiles/motion-design-skill

Usamos a tabela de durações dela para conferir o tempo das entradas do vídeo.

6. Design DNA

Analisa prints de referência e devolve um perfil com cores, fontes, espaçamentos e efeitos. Depois cria o design a partir desse perfil.

npx skills add zanwei/design-dna

Bom para usar uma referência sem copiar o post de ninguém.

7. Genjutsu

Lê o seu projeto, propõe a interação e aplica. Tem uma lista de sinais que entregam um design feito por IA.

npx skills add https://genjutsu.athevon.dev -g

Instale pela URL, como no comando. Pelo repositório (AThevon/genjutsu), as skills vêm sem os módulos.

Por onde começar

Se você quer só um vídeo curto para o Instagram, comece pelo HyperFrames: ele já instala o GSAP junto na prática e entrega o MP4. Se quer melhorar animações de um site, vá de Motion Design e Genjutsu. Three.js só se precisar de 3D.
