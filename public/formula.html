A fórmula do prompt que funciona

Papel, tarefa, contexto e formato. Preencha o modelo e veja a diferença na primeira resposta.

Como usar: copie o modelo, troque o que está entre [colchetes] e cole no Claude, no ChatGPT ou no Gemini.

1. Modelo para preencher

Use sempre nessa ordem. Nenhuma parte é opcional.

Aja como [especialista] com experiência em [área].

Tarefa: [verbo + o que você quer].

Contexto:
- Para quem é: [público].
- Objetivo: [o que deve acontecer depois].
- Já tentei / já tenho: [...].
- Evite: [...].

Formato: [tabela / lista / e-mail / texto corrido], com até [tamanho].

2. Exemplo: legenda para negócio local

Para quem vende no bairro.

Aja como redator de uma cafeteria de bairro.

Tarefa: escreva 3 legendas para o lançamento do café gelado.

Contexto: o público é quem trabalha perto e passa no almoço. Tom leve, sem clichê. Evite hashtags no meio do texto.

Formato: 3 opções, até 40 palavras cada, com uma chamada para visitar a loja.

3. Exemplo: e-mail de trabalho

Para pedir algo sem parecer cobrança.

Aja como gestor de projetos experiente.

Tarefa: escreva um e-mail pedindo para o fornecedor antecipar a entrega.

Contexto: o prazo atual é dia [data] e precisamos para [data]. A relação é boa e queremos manter. Evite tom de cobrança.

Formato: e-mail curto, até 120 palavras, com assunto.

4. Exemplo: estudo

Para entender um assunto do zero.

Aja como professor paciente de [matéria].

Tarefa: explique [conceito].

Contexto: sou iniciante e já li [o que você já leu], mas não entendi [ponto].

Formato: uma analogia do dia a dia, depois 3 tópicos curtos e uma pergunta para eu testar se entendi.

Bônus

Se a resposta vier boa, peça: “transforme isso em um modelo reutilizável para mim”. Você monta a sua biblioteca de prompts sem esforço.
